Cheque Printer

Date, Pay to aur amount bharein. Amount khud words mein badal jayega, PDF cheque ke size par banegi.

Cheque bharein

Amount in words-
  1. PDF kholein aur print mein Actual size / 100% chunein ("Fit to page" band).
  2. Pehli dafa plain kaghaz par Test print nikaal kar cheque ke peeche roshni mein milayein.
  3. Farq ho to layout mein X/Y theek karein, ya preview mein field ko drag karein.

Preview

Neela text woh hai jo print hoga, baqi cheque ka design sirf andaze ke liye hai. Kisi field ko drag kar ke us ki jagah badal sakte hain, ye har bank ke liye alag save hoti hai.

Layout & printer settings:

X = baayein kinare se, Y = upar kinare se (mm, text ki base line). Date ka X pehle box ka center hai aur "Box gap" har box ka faasla.

Cheque register

Register aur layouts isi browser mein save hote hain. Doosre computer par istemal ke liye "Layout file save karein" se file nikaal kar wahan load kar lein.
